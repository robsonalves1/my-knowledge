# Knowledge

A personal repository where I collect what I learn from books, courses, articles, videos, and other sources.

## Purpose

The goal of this repository is to turn reading and studying into something I can keep, review, and build on. Writing notes in my own words helps me understand a topic better, and having everything in one place makes it easy to find later.

This repository is for:

- Notes and summaries from books I read
- Lessons from courses, tutorials, and videos
- Concepts I am learning, explained in my own words
- Code examples and experiments I have actually run
- Useful links, references, and questions to explore later

## Note template

Every note follows a simple format:

```markdown
# Title

**Source:** book / course / article name and author
**Date:** YYYY-MM-DD
**Status:** reading | finished | to review

## Summary
The main idea in a few sentences, in my own words.

## Examples
Code or real-world examples.

## My takeaways

## Questions / next steps
What I still don't understand or want to explore.
```

## Principles

- **My own words.** Notes are written in my own words, not copied from the source. Short quotes are fine, with the source credited.
- **Small and frequent.** A short note written today beats a perfect note never finished.
- **Practice over theory.** Where possible, I include examples I have tried myself.
- **Review.** I revisit old notes and improve them as my understanding grows.
- **No secrets.** No passwords, API keys, or personal data are ever committed.
